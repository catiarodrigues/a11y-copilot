A CLI accessibility auditor built on a 3-agent pipeline — Planning, Execution, Validation —
that never calls a fix "confirmed" without simulating it first. It scans a rendered page,
grounds each fix in real WCAG 2.2 / ARIA APG guidance, and validates every fix against a
cloned copy of the page before ever reporting it. It never modifies your live page or your
source files.

## Install

```bash
npm install -g @catiarodrigues/a11y-copilot
```

```bash
a11y-copilot audit <url>
```

See [Getting started](/guides/getting-started/) for the full setup (API key or mock mode),
or [Commands](/guides/commands/) for every flag.

## How it works

<CardGrid stagger>
	<Card title="Scan" icon="magnifier">
		[axe-core](https://github.com/dequelabs/axe-core) driven through [Playwright](https://playwright.dev/), against the real rendered DOM — works against any framework.
	</Card>
	<Card title="Ground" icon="open-book">
		Every explanation is grounded in a local RAG index over the WCAG 2.2 / ARIA APG corpus — no API cost, no external vector DB.
	</Card>
	<Card title="Fix" icon="setting">
		The Execution agent proposes a concrete DOM patch per violation via [MCP](https://modelcontextprotocol.io) tools.
	</Card>
	<Card title="Validate" icon="approve-check">
		The fix is simulated against a cloned copy of the page and re-scanned. A fix is only "confirmed" once axe-core agrees — never on the model's word alone.
	</Card>
</CardGrid>
